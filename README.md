# 观澜股票

运行在自己电脑上的 A 股桌面分析软件，第一版支持 macOS。

## GitHub 网页版

网页发布在 GitHub Pages；`docs/` 是初始网页和公开数据种子，GitHub Actions 会使用更新后的数据重新构建并部署，最新采集数据不必写回仓库提交历史。

网页保留自选、行情快照、K线与指标、条件选股、四个区间榜单，以及沪深300/上证50/科创50 ETF 集中度、市值与份额图。合计与单只市值共用一张图，支持勾选、季度联动和导出。

**网页定时自动获取数据，不是逐笔实时行情。** 北京时间周一至周五09:30–11:30、13:00–15:00，每15分钟安排一次行情抓取与发布；16:35再抓取全市场日线并发布。GitHub任务排队及行情源限流可能造成延迟，休市日仍显示行情源实际时间。ETF规模按季度披露，定时检查已公布报告。

页面每5分钟检查新发布数据，更新按钮也可检查最新快照；页面始终标注行情快照时间、日线截止日和ETF报告期。排行榜只接受快照覆盖的日期。数据源失败时保留上次有效数据，并标出更新异常，不把旧数据伪装成实时行情。

自动任务位于 `.github/workflows/refresh-pages.yml`，运行日志和成功/失败状态可在仓库 Actions 查看。可在“Run workflow”中勾选 history 手动补齐全市场日线。任务只使用GitHub内建的临时发布身份，不向浏览器下发令牌。

自选股和最近一次排行榜只保存在当前浏览器。仓库中不包含桌面版自选列表、个人排行结果、应用数据目录或认证凭据。发布的是公开全市场行情和ETF数据；浏览器不需要GitHub令牌。

更新公开数据并部署：

```sh
npm run web:collect              # 更新市场、指数和三组ETF快照
npm run web:collect -- --history # 可选：采集全市场完整日线，扩大可计算日期范围
npm run web:build                # 只导出白名单中的公开数据；缺失时保留上次有效快照
npm run web:deploy               # 提交docs并推送，GitHub Pages自动重新发布
```

初次导入桌面版的公开行情缓存时，可使用 `node scripts/build-pages.cjs --data-dir <公开行情缓存目录> --indices-file data/web-indices.json`。构建脚本只读取 `market.json`、指数快照、历史行情和ETF季度数据，不读取 `watchlist.json` 或 `last-ranking.json`。

## 打开软件

双击 `release/观澜股票-darwin-x64/观澜股票.app`。使用已打包的应用无需安装 Node.js 或 Python。

## 已有功能

- 沪深北 A 股公开行情、四个主要指数，30 秒刷新。
- 股票代码、名称、拼音搜索，自选股在本机持久保存。
- 前复权日 / 周 / 月 K 线、成交量、MA5 / MA10 / MA20、MACD(12,26,9)、RSI(14)。
- 全 A 股条件选股：股价、涨跌幅、换手率、成交额、动态市盈率、交易所，支持排除 ST 和无成交股票。
- 区间涨幅榜、区间跌幅榜、最大回撤榜、最大涨幅榜，支持全 A 股或自选股范围。
- 行情、K 线、选股结果和榜单导出为 UTF-8 CSV。
- 排行进度、停止计算、本机历史缓存、失败与跳过计数。
- 沪深300、上证50、科创50 ETF 分析：头部集中度、指数流通市值占比、合计与单只市值、总份额变动；近 1 / 3 / 5 年，支持曲线勾选、季度联动和导出。

## ETF 占比图口径

从天天基金普通沪深300 ETF 候选名单中，排除联接、增强和沪深300衍生指数产品。

默认的集中度 = 当季上市市值最大的头部基金合计市值 ÷ 当季该指数全部候选普通 ETF 合计流通市值 × 100%。最多取10只，实际不足10只取全部。沪深300、上证50、科创50独立计算，不能跨指数混合分母。每只基金用当季披露总份额乘以同一个月末交易日的未复权收盘价估算；普通上市 ETF 的披露总份额用于估算流通份额。缺少任意一只的当季报告或同日价格，集中度及合计曲线该季度留空。上市前的基金不纳入当季分母。

合计市值图每季重新选前十；单只市值图采用最新完整季度前十的固定名单，追踪各自历史值。单只曲线只要求该基金当季份额与共同价格日期完整，其他基金的数据缺失不会抹掉它已有的数据。

切换到原有的指数流通市值分母时，逐季度按期末净资产排名取前十：

1. 净资产规模占比：当期前十只净资产合计，除以上交所披露的同期沪深300流通市值。
2. 上市市值占比估算：各基金当期总份额（亿份）乘以未复权月末收盘价（元），得到亿元市值；合计后除以相同的流通市值分母。

份额公开值精确到 0.01 亿份，上市市值为估算。季度末休市时，指数市值和 ETF 价格匹配同一个月末交易日。仅绘制已披露且数据完整的季度，缺失值不插值，也不用当前份额回填历史。当前候选名单可能不含已终止或无法检索的基金。数据为季度披露频率，不代表每日或盘中占比；净资产含现金等资产，也不等同于实际股票持仓比例。

来源：[上交所上证统计月报](https://www.sse.com.cn/aboutus/publication/monthly/index/)、[天天基金规模变动](https://fundf10.eastmoney.com/gmbd_510300.html)、[腾讯证券](https://gu.qq.com/sh510300)。

## 四个榜单的计算口径

所有指标使用**前复权日线收盘价**。设有效交易日收盘价序列为 `P[0] ... P[n]`：

| 指标 | 计算 |
| --- | --- |
| 区间涨跌幅 | `(P[n] / P[0] - 1) × 100%`；涨幅榜仅列正值，跌幅榜仅列负值 |
| 最大回撤 | 对每个日期，以此前最高收盘价为高点计算跌幅，取最大值；先高后低 |
| 最大涨幅 | 对每个日期，以此前最低收盘价为低点计算涨幅，取最大值；先低后高 |

回撤以正数表示跌幅；单调上涨时回撤为 0，单调下跌时最大涨幅为 0。表格展示对应高低点日期。

- 最长区间为两年。日线接口每次约 640 根，未实现任意多年区间。
- 起止日期为自然日，实际采用区间内首末有效交易日。新上市和停牌股票可能覆盖更短区间，表格会显示有效起止日期。
- 少于两个有效收盘价的股票跳过，接口失败单独计数。
- 全市场范围采用当前公开股票池；备用源不足时用有日期的上市名单快照补充，并标明快照日期。不能替代含完整退市样本的无偏历史回测。
- 未完成、已停止或有失败时，界面与导出文件注明状态和处理数量。结果不是完整全市场排行。
- 不计算盘中极值，不含佣金、印花税、滑点或分红再投资。
- 全市场首次计算需要逐只请求历史数据，可能需要数分钟或更久。最多 4 个并行请求，缓存复用。停止操作等待已发出的请求结束后完成。

## 数据与隐私

- 腾讯证券公开行情：个股和指数快照、搜索、前复权历史 K 线；东方财富为历史行情备用源。
- 东方财富公开行情：沪深北 A 股股票池与筛选快照，缓存 5 分钟；连接中断时使用新浪财经备用行情。
- 数据直接从公开接口读取，不上传自选股或排行结果到自建服务器。股票代码等查询参数会发送给对应行情服务。
- 桌面版数据目录：`~/Library/Application Support/观澜股票/data`。实际路径可在软件「数据与设置」查看。
- 开发预览数据目录：项目下 `data/`，与正式桌面版隔离。
- 公开接口不提供可依赖的可用性与延时保证；数据可能缺失或被限流，软件会显示错误或注明过期快照，不生成模拟行情。
- 不连接券商、不下单，无账户登录和云端同步。

## 开发

需要 Node.js 22.12 或更新版本。

```sh
npm install
npx install-electron
npm start
```

Electron 45 将运行程序下载拆分为显式的 `install-electron` 命令。若需要指定缓存目录：

```sh
electron_config_cache="$PWD/.cache/electron" npx install-electron
```

```sh
npm test          # 数学口径、本地存储、请求来源和任务状态测试
npm run preview   # 仅开发预览 http://127.0.0.1:8765
npm run package   # 为当前 Mac 架构生成 .app
```

源代码不依赖前端构建服务，所有界面资源随桌面应用打包。Electron 窗口启用隔离与沙箱，关闭 Node 集成，拒绝页面权限和外部导航；本机服务仅监听回环地址，并校验请求来源。

该版本为本机使用的未公证开发版本。跨电脑分发前需要适配目标系统、签名、公证，并进一步验证数据接口稳定性。

参考：[Electron 安全指南](https://www.electronjs.org/docs/latest/tutorial/security)、[AKShare 股票数据资料](https://akshare.akfamily.xyz/data/stock/stock.html)。
